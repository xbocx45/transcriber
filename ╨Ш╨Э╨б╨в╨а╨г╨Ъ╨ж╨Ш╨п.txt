СЕРВЕР РАСШИФРОВКИ РЕЧИ, версия 1.0
Голосовые, записи звонков и видео в текст. Работает на вашем сервере, без оплаты за минуты.
Распознаватель: Whisper (модель large-v3-turbo), русский язык.

ЧТО УМЕЕТ
  Расшифровывает голосовые для бота MAX ("Контент с производства").
  Расшифровывает звонки: если в записи каждый собеседник на своей дорожке (так пишут
  большинство телефоний и Битрикс24), текст выходит по ролям: "Менеджер: ... Клиент: ...".
  Если запись в одну дорожку, будет общий текст без разделения по ролям.
  Страница в браузере: открыли адрес сервера, вставили ключ, перетащили файл, получили текст.
  Подключается к любым программам: свой формат и формат OpenAI Whisper (многие программы его понимают).
  Отдельный ключ для каждой программы, статистика минут по каждому ключу.


КАКОЙ СЕРВЕР КУПИТЬ
  Ubuntu 24.04 (или 22.04), 4 ядра процессора, 8 ГБ памяти, диск от 40 ГБ.
  Видеокарта не нужна. Подойдет обычный облачный сервер (VPS) у российского хостинга.
  На 4 ГБ памяти тоже заработает, но поставится модель попроще (small), текст будет хуже.
  Скорость на 4 ядрах примерно: минутное голосовое расшифровывается за полминуты-минуту.
  Точнее покажет первая расшифровка (время пишется под текстом на странице).


УСТАНОВКА (около 15 минут, почти все время уходит на скачивание)
Шаг 1. Создайте на GitHub новый репозиторий, например transcriber.
       Его можно сделать публичным: ключей и паролей в этих файлах нет.
       Загрузите туда файлы: app.py, index.html, requirements.txt, install.sh, ИНСТРУКЦИЯ.txt
Шаг 2. Откройте консоль сервера (в панели хостинга кнопка "Консоль" или подключение по SSH)
       и выполните одну строку, заменив ВАШ_ЛОГИН на ваш логин GitHub:

       apt-get install -y git && git clone https://github.com/ВАШ_ЛОГИН/transcriber && cd transcriber && sudo bash install.sh

       Если хотите свой адрес (например stt.вашсайт.ru), сначала направьте его на IP сервера
       (запись A в DNS), а последнюю часть команды замените на:
       sudo DOMAIN=stt.вашсайт.ru bash install.sh
       Без своего домена сервер получит адрес вида 185-1-2-3.sslip.io с https, это нормально.

Шаг 3. В конце установка напечатает адрес и два ключа. Сохраните их.
       Посмотреть ключи потом:  sudo cat /etc/transcriber.env

Шаг 4. Проверьте: откройте в браузере https://АДРЕС/health
       Должно быть "ok": true. Если "загружаю модель", подождите минуту.


ПОДКЛЮЧИТЬ К БОТУ MAX
  В Bothost, в переменных бота, добавьте:
    WHISPER_URL   = https://АДРЕС (без / в конце)
    WHISPER_TOKEN = ключ "для бота MAX" из шага 3
  Перезапустите бота. В админке бота, на странице "Настройка", пункт "Расшифровка голосовых"
  станет зеленым. Кнопка "Проверить расшифровку" отправит тестовый звук.


ПОДКЛЮЧИТЬ ДРУГУЮ ПРОГРАММУ
  Новый ключ для нее:  sudo transcriber-addkey crm
  Если программа умеет работать с OpenAI Whisper, укажите в ее настройках:
    адрес (base URL):  https://АДРЕС/v1
    ключ (API key):    новый ключ
    модель:            whisper-1 (любое значение)
  Если программу пишет разработчик, ему хватит этого:
    POST https://АДРЕС/v1/transcribe
    заголовок  Authorization: Bearer КЛЮЧ
    поля формы: file (файл), speakers (auto / mono / stereo), names ("Менеджер, Клиент"),
                prompt (термины-подсказки), wait (1 ждать результат, 0 вернуть номер задания)
    результат долгой записи: GET https://АДРЕС/v1/jobs/НОМЕР
    статистика минут:        GET https://АДРЕС/v1/stats


ОБСЛУЖИВАНИЕ
  Обновить программу:      cd transcriber && git pull && sudo bash install.sh
  Журнал работы:           sudo journalctl -u transcriber -f
  Перезапустить:           sudo systemctl restart transcriber
  Сменить модель:          поменять MODEL в /etc/transcriber.env и запустить install.sh еще раз
  Ключи, настройки и скачанная модель при обновлении сохраняются.
  Сервер сам запускается после перезагрузки. Задания, которые не успели расшифроваться
  до перезапуска, доделываются автоматически.


БЕЗОПАСНОСТЬ
  Без ключа сервер ничего не расшифровывает. После 20 неверных ключей за 10 минут адрес блокируется.
  Связь только по https. Файлы удаляются сразу после расшифровки, результаты хранятся 7 дней.
  Сайт закрыт от поисковиков.
